# FutureSchool AI

BBGNight okul etkinliği için yapay zekâ destekli STEM tasarım oyunu.

## Ürün döngüsü
Tasarla → Ölç → AI ile sorgula → Yeniden tasarla → Savun → Sergile

## Dokümantasyon düzeni
- `CLAUDE.md`: Claude Code çalışma protokolü
- `docs/product-bible/`: ürünün yaşayan anayasası
- `docs/ux/`: akışlar, ekranlar, tasarım sistemi ve fiziksel sergi
- `docs/architecture/`: teknik mimari, veri modeli, güvenlik, test ve deployment
- `docs/decisions/`: mimari karar kayıtları (ADR)
- `docs/sprints/`: Claude Code'un oluşturacağı ve tamamladıkça arşivleyeceği sprint dosyaları

## Başlangıç durumu
Henüz kod yok. Önce Sprint 0 ile ürün kararları doğrulanacak; sonra Claude Code sprinti planlayıp uygulayacak.
