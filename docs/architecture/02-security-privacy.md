# Security & Privacy

- Öğrenci adı/soyadı zorunlu değildir; takım rumuzu yeterlidir.
- Konum, sağlık verisi, e-posta, telefon, fotoğraf uygulamada toplanmaz.
- AI'ya yalnızca tasarım metrikleri ve öğrenci proje gerekçesi gönderilir.
- API anahtarı istemciye gömülmez.
- QR çıktısı kişisel veriye yönlenmez.
- Varsayılan olarak kalıcı öğrenci hesabı/veritabanı yoktur.
- AI başarısızlığı core oyunu durdurmaz.
