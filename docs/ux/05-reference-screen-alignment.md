# Reference Screen Alignment

Onaylanan UX referansı uygulamada aşağıdaki sırayla karşılanır:

1. Hoş Geldin Ekranı
2. Takım Oluştur
3. Görev ve Senaryo
4. Tasarım Alanı (Grid)
5. Sonuçlar ve Analiz
6. AI Bilim Danışmanı
7. 2040 Olay Kartı
8. Yeniden Tasarla
9. Sonuç Raporu
10. Paylaş ve Sergile

Görsel sistem: beyaz/off-white yüzeyler, doğa yeşili ana aksiyonlar, mavi destek göstergeleri, turuncu olay/uyarı rengi, mor sosyal/aktif yaşam vurgusu. Kampüs ve robot görselleri harici servise ihtiyaç duymayan özgün CSS illüstrasyonlarıdır.
