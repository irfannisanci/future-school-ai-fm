# User Flows

## Student Team Flow
Welcome → Brief → Design → Validate rules → Analyze → Lock → AI questions → Event → Redesign → Compare → Reflect → Export

## Error flows
- bütçe aşıldı → tasarıma dön
- zorunlu yapı eksik → eksik yapıyı vurgula
- overlap/grid dışı → placement reddedilir
- AI timeout → fallback sorularına geç
- export hata → ekranda sonuç korunur ve tekrar dene

## New Team Flow
Final → Reset next team → yerel oturumu temizle → Welcome
