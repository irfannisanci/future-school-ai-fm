# Design System

## Renkler
- Navy `#17324D` — ana navigasyon/başlık
- Teal `#13817C` — AI/teknoloji
- Green `#567D46` — sürdürülebilirlik
- Off-white `#F6F8F7` — zemin
- Amber — yalnızca uyarı/limit

## Erişilebilirlik
- gövde yazısı en az 16 px
- dokunmatik hedef en az 44 px
- renk tek başına bilgi taşımamalı
- grid hücre sınırları yüksek kontrast olmalı

## Ton
Kısa, merak uyandıran, çocuklaştırmayan, bilimsel ama anlaşılır Türkçe.
