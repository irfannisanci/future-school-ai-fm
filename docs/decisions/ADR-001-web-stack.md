# ADR-001 — Web Stack

**Status:** Accepted

## Context
Ürün okul cihazlarında linkle açılmalı, hızlı geliştirilmeli ve sergiye yetişmeli.

## Decision
MVP için Next.js + React + TypeScript.

## Consequences
Tek codebase, kolay web deployment, güçlü test/tooling. Native mobil uygulama MVP dışında kalır.
