# Architecture Decision Records

ADR formatı:
- Context
- Decision
- Consequences
- Status

Yeni kalıcı mimari veya ürün-teknoloji kararı verildiğinde yeni ADR ekle. Mevcut karar değişirse eski ADR'yi silme; superseded olarak işaretle.

- ADR-002 — Local-first state

- ADR-004 — Hybrid technical score and AI jury
- ADR-005 — Event cards as a deterministic stress test
- ADR-006 — Resource–needs model for every challenge
